# TUI UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make current activity visible, stabilize the list and improve keyboard navigation.

**Architecture:** Keep application and backend ownership unchanged. Add focused TUI
helpers for activity projection, list geometry and navigation; wire them through
the existing model and centralized shortcut definitions. Render only observed state.

**Tech Stack:** Go 1.27.2, existing Bubble Tea v2/Bubbles v2/Lip Gloss v2 and Go tests.

**Spec:** `docs/superpowers/specs/2026-10-16-tui-ux-design.md`

## Global Constraints

- Go 1.27.2; retain the versions in go.mod (Bubble Tea v2, Bubbles v2, Lip Gloss v2).
- No new dependencies, backend capabilities, config fields or API polling frequency.
- Keep UI copy in English, matching the existing application.
- Preserve request generations, download references, queue identities and runtime ownership.
- Do not replay mutations or start transfers when navigating or rendering.
- Retain existing letter shortcuts unless explicitly changed below.
- Execute inline on branch `ux`; validate and commit each task before the next.

## Review Focus

- Queue resolution/overwrite without a current transfer must not show an old file or start new work.
- Narrow Unicode/ANSI content and embedded newlines must not overflow or shift footer rows.
- Hidden columns must not shift fuzzy-match highlights or invalidate sorting keys.
- Search typing and modal precedence must not accidentally quit or launch a shortcut.
- Quit cancellation must preserve nested return destinations and pending queue decisions.

Create `internal/tui/activity.go`, `layout.go`, `navigation.go` and matching focused
test files. Keep transfer ownership in downloads_model.go/bulk_download.go and
shortcut ownership in shortcuts*.go. Extend popup.go/help_overlay.go rather than
introducing a second overlay framework. No application/backend refactor.
